# ⏱ Тайм-менеджер (Spring Boot + JavaScript)

Сайт для управления задачами с Pomodoro-таймером и учётом потраченного времени.

**Что умеет:**
- задачи с приоритетом, дедлайном, описанием и статусом (к выполнению / в работе / готово);
- фильтры и сортировка (по приоритету, дедлайну, дате создания);
- Pomodoro-таймер (25/5 минут, настраивается) — нажми ▶ у задачи, и время работы будет записываться на неё;
- звуковой сигнал и уведомление в конце помидора;
- подсветка просроченных дедлайнов, общая статистика;
- данные хранятся в файле `data/timemanager.mv.db` и не пропадают после перезапуска;
- тёмная тема включается автоматически вместе с системной;
- **календарь в стиле Google Calendar** (`/calendar.html`): месяц / неделя / день / список, создание событий выделением, перетаскивание и растягивание, цвета, дедлайны задач прямо в календаре;
- **вход по логину и паролю** (задаются в `application.properties`);
- **доступ с телефона** — по Wi-Fi или из любого места через интернет.

## 🚀 Запуск без среды разработки (Windows)

### Шаг 1. Установи Java (JDK 17 или новее) — один раз
1. Зайди на https://adoptium.net
2. Скачай **Temurin 21 (LTS)** → Windows → x64 → `.msi`.
3. При установке включи пункты **«Set JAVA_HOME variable»** и **«Add to PATH»**.
4. Проверка: открой `cmd` (Win+R → `cmd`) и введи
   ```
   java -version
   ```
   Должна показаться версия 17+ (например, `openjdk version "21..."`).

### Шаг 2. Распакуй проект
Распакуй архив, например, в `C:\Projects\time-manager`.
⚠️ Лучше путь **без кириллицы и пробелов**.

### Шаг 3. Запусти `run.bat`
Двойной клик по `run.bat`. Скрипт:
1. проверит, что Java установлена;
2. один раз скачает Maven (сборщик проектов) в папку `.tools`;
3. скачает библиотеки Spring Boot (первый раз 1–3 минуты);
4. запустит сервер и откроет браузер на **http://localhost:8080**.

Пока окно консоли открыто — сайт работает. Закрыл окно (или Ctrl+C) — сервер остановлен.

## 📱 Доступ с телефона

Сначала запусти сайт через `run.bat` (окно должно оставаться открытым).

**Логин и пароль** — в файле `config/application.properties` в корне проекта
(он не попадает в git). Если его нет — скопируй `config/application.properties.example`
в `config/application.properties`, впиши свои логин и пароль и перезапусти `run.bat`.

### Вариант А: дома, по Wi-Fi
1. Двойной клик `phone-wifi.bat` → разреши права администратора (он откроет порт 8080 в брандмауэре).
2. Он покажет адрес вида `http://192.168.x.x:8080` — открой его на телефоне (телефон в той же Wi-Fi).

### Вариант Б: из любого места (мобильный интернет), даже с серым IP
1. Двойной клик `phone-internet.bat` (первый раз скачает `cloudflared` ~60 МБ).
2. Через ~10 секунд в окне появится ссылка `https://что-то.trycloudflare.com` — открой её на телефоне.
3. Ссылка меняется при каждом запуске `phone-internet.bat`. Соединение шифруется (https).

### Вариант В: белый IP + проброс порта (постоянный адрес)
1. Узнай, белый ли IP: зайди в настройки роутера (обычно `192.168.0.1` или `192.168.1.1`),
   найди «WAN IP / Интернет-адрес» и сравни с тем, что показывает https://2ip.ua.
   Совпадает → IP белый. Отличается или начинается с `10.`, `100.64–127.`, `172.16–31.`, `192.168.` → серый (используй вариант Б).
2. В роутере: «Проброс портов / Port Forwarding / Виртуальный сервер» → внешний порт 8080 → IP твоего ПК (из `phone-wifi.bat`) → порт 8080.
3. Желательно закрепить за ПК постоянный локальный IP (DHCP-резервирование в роутере).
4. На телефоне: `http://ТВОЙ_БЕЛЫЙ_IP:8080`. ⚠ Это http без шифрования — пароль обязательно сложный.

### Добавить на главный экран телефона
Открой сайт в Chrome → меню ⋮ → «Добавить на главный экран». Будет как приложение.

## 📁 Структура проекта

```
time-manager/
├── pom.xml                         ← зависимости и настройки сборки (Maven)
├── run.bat                         ← запуск одним кликом
├── phone-wifi.bat                  ← доступ с телефона по Wi-Fi
├── phone-internet.bat              ← доступ с телефона через интернет (Cloudflare Tunnel)
└── src/main/
    ├── java/com/dmitro/timemanager/
    │   ├── TimeManagerApplication.java   ← точка входа (main)
    │   ├── model/
    │   │   ├── Task.java                 ← сущность «Задача» (таблица в БД)
    │   │   ├── Event.java                ← сущность «Событие календаря»
    │   │   ├── Priority.java             ← LOW / MEDIUM / HIGH
    │   │   └── Status.java               ← TODO / IN_PROGRESS / DONE
    │   ├── repository/
    │   │   └── TaskRepository.java       ← доступ к БД (Spring Data JPA)
    │   ├── config/
    │   │   └── BasicAuthFilter.java      ← вход по логину/паролю
    │   └── controller/
    │       ├── TaskController.java       ← REST API /api/tasks
    │       └── EventController.java      ← REST API /api/events (календарь)
    └── resources/
        ├── application.properties        ← порт, настройки БД
        └── static/                       ← фронтенд (отдаётся Spring'ом)
            ├── index.html / app.js       ← страница задач + Pomodoro
            ├── calendar.html / calendar.js / calendar.css ← календарь
            ├── style.css
            └── lib/fullcalendar/         ← библиотека календаря (MIT)
```

**Как это работает:** браузер открывает `index.html` → `app.js` через `fetch()` ходит
в REST API (`TaskController`) → контроллер через `TaskRepository` читает/пишет
в базу H2 → ответ в JSON возвращается в браузер и отрисовывается.

## 🔌 REST API

| Метод  | URL                        | Что делает                       |
|--------|----------------------------|----------------------------------|
| GET    | `/api/tasks`               | список задач                     |
| POST   | `/api/tasks`               | создать задачу                   |
| PUT    | `/api/tasks/{id}`          | изменить задачу                  |
| PATCH  | `/api/tasks/{id}/status`   | сменить статус `{"status":"DONE"}` |
| POST   | `/api/tasks/{id}/time`     | добавить время `{"seconds":60}`  |
| DELETE | `/api/tasks/{id}`          | удалить задачу                   |
| GET    | `/api/stats`               | статистика                       |
| GET    | `/api/events?start=..&end=..` | события за период             |
| POST   | `/api/events`              | создать событие                  |
| PUT    | `/api/events/{id}`         | изменить событие                 |
| DELETE | `/api/events/{id}`         | удалить событие                  |

Консоль базы данных выключена (сайт доступен из сети). Чтобы включить для отладки —
`spring.h2.console.enabled=true`, адрес http://localhost:8080/h2-console
(JDBC URL: `jdbc:h2:file:./data/timemanager`, user: `sa`, пароль пустой).

## ❗ Частые проблемы

| Проблема | Решение |
|---|---|
| `Java not found` | Установи JDK (шаг 1) и **перезапусти** `run.bat`. Если не помогло — перезагрузи ПК. |
| `Port 8080 was already in use` | Сервер уже запущен в другом окне — закрой его. Или поменяй `server.port` в `application.properties`. |
| `release version 17 not supported` | Стоит старая Java (8/11). Поставь JDK 21. |
| Браузер открылся раньше, чем сервер | Подожди и обнови страницу (F5). |
| Телефон по Wi-Fi не открывает | Запусти `phone-wifi.bat` от админа; проверь, что телефон в той же сети, а не в гостевой; отключи VPN на телефоне. |
| Браузер всё время спрашивает пароль | Проверь логин/пароль в `config/application.properties`, после изменения перезапусти `run.bat`. |
| Хочу начать с чистой базы | Останови сервер и удали папку `data`. |
